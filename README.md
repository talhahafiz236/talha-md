## 🌟 Overview
**TALHA-MD** is an ultra-fast, highly resilient, and feature-rich WhatsApp Multi-Device bot built on top of `@whiskeysockets/baileys`. Engineered with an Obsidian high-tech visual design and lightning-fast sub-20ms command dispatching.

---

## ⚡ Core Features

- 🧠 **Next-Gen Gemini AI:** Instant intelligent answers, code explanations, and natural conversational AI.
- 🛡️ **Stealth Shield & Anti-Delete:** Automatically recovers and displays deleted messages, photos, and videos with full sender context.
- 👁️ **On-Demand View-Once Unlocker:** Replying `.vv`, `.rvo`, or `.viewonce` immediately reveals hidden view-once media.
- 📥 **High-Speed Media Downloader:** Download YouTube songs, MP4 videos, Instagram Reels, TikTok, and media on the fly.
- 👑 **Smart Group Management:** Anti-link enforcement, automated tagging, kick/add, demote/promote, and group administration.
- 🎨 **Obsidian Theme:** Elegant, unified monospace formatting across all 41 built-in commands.
- 🚀 **Multi-Cloud Ready:** Deployable on Render, Koyeb, Railway, Docker, or local environments.

## 🛠️ Deploy to Render (Free 24/7 Cloud)

1. Sign up / Log in to [Render.com](https://render.com).
2. Click **New +** -> **Web Service**.
3. Select your **`talha-md`** repository.
4. Set the following Environment Variables:
   - `SESSION_ID`: *(Your generated TALHA-MD session string)*
   - `OWNER_NUMBER`: `923426767199`
   - `OWNER_NAME`: `Talha Sheikh`
   - `BOT_NAME`: `Talha-MD`
   - `MODE`: `public`
   - `PREFIX`: `.`
   - `GEMINI_API_KEY`: `your_gemini_api_key_here`
5. Click **Deploy Web Service**!
