# 🌐 TALHA-MD 24/7 CLOUD DEPLOYMENT GUIDE (LAPTOP OFF HO TO BHI CHALAY)

Aap ka bot **TALHA-MD** ab mukammal tor par Cloud-Ready hai. Is guide ki madad se aap bot ko free cloud servers par deploy kar sakte hain taake **laptop band hone par bhi bot 24/7 online rahay**.

---

### 📦 Tayyar Shuda Files:
- **Zip Package:** `TALHA-MD-CLOUD.zip` (1.48 MB)
- **Session Key:** Aap ke WhatsApp par `.session` likhne se mil jati hai ya `.env` file mein mojood hai.

---

### 🚀 TARIQA 1: KOYEB (SAB SE BEHTAREEN & 100% FREE ALWAYS-ON)

Koyeb par bot kabhi sleep mode mein nahi jata aur 24/7/365 chalta rehta hai:

#### Step 1: GitHub par Files Upload Karein
1. [github.com](https://github.com) par jayein aur apna free account banayein.
2. **"New Repository"** par click karein.
3. Repository ka naam likhein: `talha-md` (Private ya Public jo chahein select karein) aur **Create** dabayein.
4. **"uploading an existing file"** par click karein.
5. Apne computer se `TALHA-MD-CLOUD.zip` ko extract kar ke uski tamam files drag & drop karein aur **Commit changes** dabayein.

#### Step 2: Koyeb par Deploy Karein
1. [koyeb.com](https://www.koyeb.com) par jayein aur **Sign in with GitHub** karein.
2. **"Create App"** button par click karein.
3. Source mein **GitHub** select karein aur apni `talha-md` repository choose karein.
4. **Environment Variables** section mein jayein aur yeh add karein:
   - `SESSION_ID` = `Aap ki TALHA-MD~... key`
   - `BOT_NAME` = `Talha-MD`
   - `OWNER_NUMBER` = `923426767199`
   - `OWNER_NAME` = `Talha Sheikh`
   - `MODE` = `public`
   - `GEMINI_API_KEY` = `your_gemini_api_key_here`
5. **Deploy** button par click kar dein!
6. 1 se 2 minute mein build complete ho jayegi aur bot cloud par 24/7 live ho jaye ga!

---

### 🚀 TARIQA 2: RENDER (1-CLICK DOCKER BLUEPRINT)

1. [render.com](https://render.com) par free account banayein.
2. **New +** $\rightarrow$ **Blueprint** ya **Web Service** select karein.
3. Apni GitHub repository `talha-md` connect karein (Render khud `render.yaml` aur `Dockerfile` detect kar leta hai).
4. `SESSION_ID` paste karein aur **Apply** dabayein.
5. Bot Render cloud server par start ho jayega!
